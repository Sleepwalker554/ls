# personal-website

Luqi Sun's academic homepage — https://sleepwalker554.github.io/personal-website

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and deployed by `.github/workflows/pages.yml`.

- Site settings / sidebar: `_config.yml`
- Top navigation: `_data/navigation.yml`
- Home, CV, Life pages: `_pages/`
- Publications & patents (one Markdown file each): `_publications/`
- Travel photos: `images/travel/`

Local preview: `bundle install && bundle exec jekyll serve`, then open http://localhost:4000/personal-website/
